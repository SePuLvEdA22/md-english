# 🗣️ No digas solo **YOU’RE WELCOME**

Amplía tu vocabulario con estas alternativas naturales y cotidianas en inglés.

---

## 💬 Expresiones y significados

| Inglés | Español |
|--------|----------|
| **No problem.** | No hay problema. |
| **Anytime.** | Cuando quieras. |
| **My pleasure.** | Un placer. |
| **Don’t mention it.** | No hay de qué. |
| **Sure thing.** | Claro. |
| **It was nothing.** | No fue nada. |
| **Glad to help.** | Encantado(a) de ayudar. |
| **You got it!** | ¡Ya está! / ¡Hecho! |
| **No worries.** | No te preocupes. |
| **Happy to help.** | Feliz de ayudar. |
| **That’s alright.** | Está bien. |
| **All good!** | Todo bien. |
| **No big deal.** | No es gran cosa. |
| **Of course!** | ¡Por supuesto! |
| **Anytime, my friend.** | Cuando quieras, amigo. |

---

## 🧩 Ejemplos prácticos

- **A:** Thanks for helping me with the project!
  **B:** *No problem!* (No hay problema)

- **A:** I really appreciate your time.
  **B:** *Anytime!* (Cuando quieras)

- **A:** Thank you for your help today.
  **B:** *My pleasure!* (Un placer)

- **A:** Thanks for covering my shift.
  **B:** *Don’t mention it.* (No hay de qué)

- **A:** Can you send me the report later?
  **B:** *Sure thing!* (Claro)

- **A:** Sorry to bother you.
  **B:** *It was nothing.* (No fue nada)

- **A:** Thanks for explaining that!
  **B:** *Glad to help!* (Encantado de ayudar)

- **A:** Can you fix my computer?
  **B:** *You got it!* (¡Hecho!)

- **A:** Sorry for the confusion.
  **B:** *No worries.* (No te preocupes)

- **A:** Thanks again for your support.
  **B:** *Happy to help!* (Feliz de ayudar)

- **A:** I’ll send it tomorrow, is that okay?
  **B:** *That’s alright.* (Está bien)

- **A:** Everything okay with the plan?
  **B:** *All good!* (Todo bien)

- **A:** Sorry, it took longer than expected.
  **B:** *No big deal.* (No es gran cosa)

- **A:** Can I use your notes?
  **B:** *Of course!* (¡Por supuesto!)

- **A:** Thanks, man!
  **B:** *Anytime, my friend!* (Cuando quieras, amigo)
